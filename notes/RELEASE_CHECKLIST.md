# Release checklist

Before any external release, the PI must confirm:

- [ ] bibliography is approved;
- [ ] author metadata and any ORCID are approved;
- [ ] Python tests and deterministic demo pass;
- [ ] arXiv source package builds cleanly after extraction;
- [ ] Elsevier CAS source package builds cleanly after extraction;
- [ ] release metadata is current;
- [ ] rendered pages have been reviewed;
- [ ] PI approval is recorded;
- [ ] external upload has **not** yet been performed.
